# Slide Type Templates

## 슬라이드 유형별 구조 가이드

각 슬라이드 유형의 표준 구조와 적용 가이드.

---

## 1. Title Slide

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│  PROJECT / DOCUMENT TITLE                    │  ← Georgia 36-44pt Bold
│  Subtitle / Description                      │  ← Arial 16pt, #464646
│                                              │
│  Date | Client | Confidential                │  ← Arial 10pt, #7D7D7D
│                                              │
│  ▌▌ (Momentum Mark)                          │  ← Orange #D04A02
└──────────────────────────────────────────────┘
```

Notes:
- White 또는 Dark (#1A1A1A) Background
- Momentum Mark (두 개의 Orange Bar) 하단 배치
- 로고는 최소 크기로

---

## 2. Executive Summary Slide

```
┌──────────────────────────────────────────────┐
│  ACTION TITLE: [핵심 결론 1문장]              │
├──────────────────────────────────────────────┤
│ ┌──────────────┐  ┌──────────────┐           │
│ │  SITUATION   │  │  CHALLENGES  │           │
│ │  현재 상황    │  │  핵심 과제    │           │
│ │              │  │              │           │
│ ├──────────────┤  ├──────────────┤           │
│ │  DIRECTION   │  │  OUTCOMES    │           │
│ │  전략 방향    │  │  기대 성과    │           │
│ │              │  │              │           │
│ └──────────────┘  └──────────────┘           │
├──────────────────────────────────────────────┤
│  ▌BUMPER: [의사결정 Implication]              │
└──────────────────────────────────────────────┘
```

Notes:
- 4-Quadrant Layout
- 각 Quadrant에 3-5개 Bullet (짧고 강력하게)
- Light Gray (#F5F5F5) Card Background

## 3. Comparison Slide (Before/After, As-Is/To-Be)

```
┌──────────────────────────────────────────────┐
│  ACTION TITLE: [변화의 핵심 효과 1문장]        │
├─────────────────────┬────────────────────────┤
│     AS-IS / BEFORE  │    TO-BE / AFTER       │
│     ──────────────  │    ──────────────       │
│     • Item 1        │    • Item 1 (improved)  │
│     • Item 2        │    • Item 2 (new)       │
│     • Item 3        │    • Item 3 (changed)   │
│                     │                        │
│   (Gray #7D7D7D)    │   (Orange #D04A02)     │
├─────────────────────┴────────────────────────┤
│  ▌BUMPER: [전환의 비즈니스 가치]              │
└──────────────────────────────────────────────┘
```

Notes:
- Before: Gray 톤 / After: Orange Accent
- 화살표(→)로 변화 강조 가능
- 변화 항목 Bold 처리

Notes:
- 슬라이드당 차트 1개만
- Key Data Point: Orange Highlight
- Source 필수

## 5. Process Flow / Pipeline Slide

```
┌──────────────────────────────────────────────┐
│  ACTION TITLE: [프로세스 핵심 가치 1문장]      │
├──────────────────────────────────────────────┤
│                                              │
│  ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐     │
│  │ 1 │ → │ 2 │ → │ 3 │ → │ 4 │ → │ 5 │     │
│  │   │   │   │   │   │   │   │   │   │     │
│  └───┘   └───┘   └───┘   └───┘   └───┘     │
│  Label   Label   Label   Label   Label      │
│  Desc    Desc    Desc    Desc    Desc       │
│                                              │
├──────────────────────────────────────────────┤
│  ▌BUMPER: [프로세스 도입의 기대 효과]          │

```

Notes:
- 수평 흐름, 좌→우
- 5-7단계 최대
- 현재 단계 Orange Highlight
- Icon in Circle 옵션

## 10. Appendix / Backup Slide

```
┌──────────────────────────────────────────────┐
│  APPENDIX: [상세 제목]                        │  ← "APPENDIX" 라벨
├──────────────────────────────────────────────┤
│                                              │
│  [Detailed Content]                          │
│  - 상세 데이터, 추가 분석, 참조 자료           │
│  - 본문에서 참조된 보충 자료                   │
│                                              │
├──────────────────────────────────────────────┤
│  Source: [Attribution]                        │
└──────────────────────────────────────────────┘
```

Notes:
- "APPENDIX" 라벨로 본문과 구분
- Bumper Statement 불필요
- 프레젠테이션 시 건너뛰되 Q&A 시 참조
